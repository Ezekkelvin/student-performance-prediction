ABOUT THE SYSTEM

Student Performance Prediction System

A machine learning-based web application designed to support student performance monitoring and early academic intervention.

SYSTEM OVERVIEW

From prediction to early intervention

The system uses machine learning to predict a student's likely performance category before the final examination. The Class Advisor enters the student's academic information and receives a prediction of Excellent, Average or At Risk.

When a student is classified as At Risk, the system provides an early intervention feature that allows the Class Advisor to notify the lecturer responsible for the selected course. This supports timely review and possible academic intervention.

01

Machine Learning

The system uses a trained machine learning classification model to predict student performance.

02

Performance Monitoring

Academic indicators such as attendance, assessment scores, previous CGPA and class participation are analysed.

03

Early Intervention

Students identified as At Risk can be flagged for possible academic intervention.

04

Lecturer Notification

The Class Advisor can notify the lecturer responsible for the selected course when intervention may be required.
